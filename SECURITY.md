# Security Policy

## Reporting a Vulnerability
If you discover a security issue related to The OSINT Grid or any associated tooling, please report it responsibly.

Email:
security@theosintvault.io

Include:
- A clear description of the issue
- Steps to reproduce (if applicable)
- Any relevant URLs or data
- Your contact information for follow‑up

## Scope
This policy applies to:
- The OSINT Grid dataset
- Metadata and documentation
- Any future API or CLI integrations

## Expectations
We will:
- Acknowledge your report
- Investigate promptly
- Provide updates as needed
- Credit responsible disclosures (optional)
