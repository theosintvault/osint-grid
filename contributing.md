# Contributing to The OSINT Grid

Thank you for your interest in contributing to The OSINT Grid. This project maintains a curated index of verified public records sources used in investigative, compliance, and intelligence workflows.

## How to Contribute

### 1. Adding or Updating a Source
If you want to add or update a public records source:
- Ensure the source is legitimate, publicly accessible, and operational.
- Confirm the correct category (corporate, property, court, licensing, government, etc.).
- Include a clear description of what the source provides.
- Follow the structure defined in `data/sources.schema.json`.

### 2. Submitting Changes
- Fork the repository.
- Create a new branch for your update.
- Commit your changes with a clear message.
- Open a pull request describing what you added or modified.

### 3. Reporting Issues
If you find a broken link, deprecated source, or incorrect category:
- Open an issue with the source name, URL, and details.

## Standards
All contributions must maintain:
- Accuracy
- Source reliability
- Clear categorization
- Consistent formatting

Thank you for helping strengthen The OSINT Grid.
