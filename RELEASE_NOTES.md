# The OSINT Grid v0.1.0

Release date: September 17, 2026

## Overview

The first public release of The OSINT Grid establishes the repository as a maintained directory of public-records sources and the data structure used to organize them.

## Included

- Public project documentation
- Machine-readable source catalog
- JSON schema for source records
- Data contribution guidance
- Repository contribution guidelines
- Issue templates for bugs and feature requests
- Pull request template
- Machine-readable project documentation
- Integration notes for The OSINT Vault Toolkit

## Source record fields

The catalog uses the following fields:

- `id`
- `name`
- `url`
- `category`
- `jurisdiction`
- `description`
- `status`

## Notes

This release provides the project structure and starter catalog. Source links and operational status should be checked before use because public websites, access requirements, and terms can change.
