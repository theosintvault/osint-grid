# Contributing to The OSINT Grid

Thanks for your interest in improving The OSINT Grid.

## Scope

We welcome contributions that improve:

- source quality and coverage
- schema clarity
- documentation and onboarding
- validation and tooling support
- project discoverability and maintainability

## Before you contribute

- Read the project purpose in `README.md`.
- Keep work aligned with lawful, ethical, and privacy-conscious research practices.
- Verify source information before including or updating records.
- Do not submit misleading or fabricated source entries.

## Suggested workflow

1. Open or review an issue for the proposed change.
2. Create a branch for your work.
3. Keep changes focused and well-documented.
4. Validate JSON and schema updates.
5. Submit a pull request with a clear explanation of the change.

## Data contribution standards

When editing `data/sources.json`:

- keep `id` values unique and stable
- prefer official source URLs
- use consistent category names
- use clear and accurate jurisdiction labels
- mark obsolete sources as `deprecated` instead of deleting them silently

## Documentation standards

- keep language factual and precise
- avoid unsupported claims about availability or legality
- distinguish project scope from source-specific permissions or terms

## Pull request checklist

- The change is clearly described.
- Documentation is updated when needed.
- Data entries are valid JSON.
- The schema still matches the file structure.
- The repository remains aligned with lawful and ethical use.

## Questions

Open an issue or reach out via the project contact email listed in the README.
