# Documentation

This directory contains project-level documentation for the OSINT Grid.

## Files

- `overview.md` — mission, categories, purpose, and roadmap
- `multi-search-launcher.md` — usage and participation guidance for the multi-search launcher

## Overview

The OSINT Grid is a structured index of verified public-records sources curated by The OSINT Vault. It is designed to help investigators, analysts, journalists, compliance teams, and digital-risk professionals locate relevant sources faster and maintain a consistent research baseline.

## Planned development

The project documentation identifies future work in the following areas:

- API access
- Automated source validation
- Uptime monitoring
- Expanded international coverage
- Category-level analytics
- CLI integration

## Contribution expectations

Documentation updates should be factual, concise, and aligned with the repository’s lawful research scope. Avoid unsupported claims about source availability, completeness, or legal access.
