# Launch post

## The OSINT Grid is now public

The OSINT Grid is a practical directory of public-records sources for investigators, researchers, journalists, compliance teams, and due diligence work.

It brings business registries, property records, court systems, licensing databases, government directories, and other public sources into one organized project.

The repository includes:

- a machine-readable source catalog
- a JSON schema for consistent records
- documentation for contributors
- project context for developers and research tools
- a roadmap for validation, APIs, analytics, and broader coverage

The goal is simple: make it easier to find the right public source before starting research.

Use the repository here:
https://github.com/theosintvault/osint-grid

Live tool:
https://theosintvault.io/osint-grid

Corrections, source suggestions, and documentation improvements are welcome. Please review the contribution guide before submitting changes.

Use public information responsibly. Always check a source's current terms, availability, and legal requirements.
