# Support for The OSINT Grid

If you need help using The OSINT Grid or have questions about the dataset, this page outlines the available support channels.

## General Questions
For general inquiries about the project, open a GitHub issue:
https://github.com/theosintvault/osint-grid/issues

## Bug Reports
If you encounter a broken link, incorrect category, or dataset error:
- Open an issue with clear details
- Include the source name and URL
- Provide steps to reproduce if applicable

## Feature Requests
If you want to suggest improvements or new capabilities:
- Open a feature request issue
- Describe the use case and expected behavior

## Direct Contact
For private or sensitive matters:
theosintvault@gmail.com

Thank you for helping improve The OSINT Grid.
